# Cycles

A **cycle** is a time-boxed slice of work scoped from a single Linear story (or a
tight cluster of sub-issues), captured here as a lean, steerable plan *before*
implementation.

How a cycle differs from a `../features/*` spec:

- A **feature** README documents a system's intended and implemented state — it
  trails the code.
- A **cycle** documents *the plan for one push of work*: why, scope, build order,
  and the decisions to revisit. It is deliberately minimal and is expected to be
  refactored as direction firms up.
